# 05 인수 기준

- **언제**: 평가 고정 goal 이 도는 동안(5분).
- **목적**: "다 됐다"를 무엇으로 확인할지 상위 요구 3~5개와 그 하위 조건으로 미리 정한다. 작은 하위 조건(실패했을 때의 표시 같은 것)을 놓치지 않기 위한 점검표이지, 기능을 늘리는 목록이 아니다.

```
[인수 기준] 코드는 쓰지 마.
과제 문서와 PLAN.md의 담당자 답만 보고 인수 기준을 만들어줘. 상위 요구는 3~5개로 묶되,
요구에 적힌 하위 조건은 개수 제한 없이 한 행씩 따로 둬(예: 결과 표시 / 실패했을 때의 대체 동작 / 대체 결과임을 구분해 표시).
기준마다 근거 문장을 인용하고, 산출물(화면 · 출력 · 파일)이나 명령으로 확인할 방법을 적어줘.
요구에 없는 것은 넣지 마.
열: 상위 요구 | 하위 조건 | 근거 문장 | 확인할 곳(산출물 · 명령) | 상태(없음 · 부분 · 실행 확인 · 미확인)
```

- 결과를 PLAN.md 6번에 넣고, 내가 한 줄씩 읽어 과한 것은 지운다.
