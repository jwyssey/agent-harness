# 05 인수 기준

- **언제**: 평가 고정 goal 이 도는 동안(5분).
- **목적**: "다 됐다"를 무엇으로 확인할지 3~5개로 미리 정한다. 작은 하위 조건(실패했을 때의 표시 같은 것)을 놓치지 않기 위한 점검표이지, 기능을 늘리는 목록이 아니다.

```
[인수 기준] 코드는 쓰지 마.
과제 문서와 PLAN.md의 담당자 답만 보고 인수 기준 3~5개를 만들어줘.
기준마다 근거 문장을 인용하고, 사용자 화면이나 파일 · 명령으로 확인할 방법을 적어줘.
요구가 여러 조건을 묶고 있으면 쪼개(예: 결과 표시 / 실패했을 때의 대체 동작 / 대체 결과임을 화면에 구분해 표시).
요구에 없는 것은 넣지 마.
열: 기준 | 근거 문장 | 확인할 곳(화면 · 파일 · 명령) | 지금 상태(없음 · 계획 · 있음)
```

- 결과를 PLAN.md 6번에 넣고, 내가 한 줄씩 읽어 과한 것은 지운다.
