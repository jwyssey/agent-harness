# ARCHITECTURE

## 의존성 방향
기존 코드가 있으면 그 구조를 그대로 적는다. 새로 짤 때만 아래 기본형에서 시작한다.
```
ui → service → model / data        (역방향 호출 금지)
```

## 상태 소유

|---|---|---|---|---|
|  |  |  |  |  |
